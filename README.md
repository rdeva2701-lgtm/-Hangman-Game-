# 🎮 Hangman Game

A simple text-based Hangman game developed in Python.

## Features

- Random word selection
- 5 predefined words
- Maximum 6 wrong guesses
- Shows guessed letters
- Win/Lose messages
- Play again option

## Concepts Used

- random module
- while loop
- if-else
- strings
- lists
- functions
- input/output

## How to Run

```bash
python hangman.py
```

Enjoy!
